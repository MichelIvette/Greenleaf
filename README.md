## Descripción

**Greenleaf** es una aplicación móvil desarrollada en Android Studio, que funciona como una aplicación de compra en línea con opción de recogida en tienda por el momento, incorporando un catálogo interactivo de plantas para la tienda especializada “Greenleaf”, con funcionalidades básicas de administración. 

---

## Requisitos del Sistema

**Software necesario:**
- Android Studio (versión reciente)
- JetBrains Runtime (JDK 21 incluido con Android Studio)
- Firebase 
- Gradle (incluido en Android Studio)
- Git + GitHub
- Emulador / dispositivo físico

## Estado actual del proyecto

Esta aplicación contaba originalmente con una base de datos en **Firebase**, la cual estuvo activa durante un periodo determinado bajo un plan de servicio temporal.

Actualmente, dicho servicio ya no se encuentra activo, por lo que:
- No es posible realizar nuevos registros de usuarios.
- No se visualizan las imágenes almacenadas de las plantas.
- Algunas funcionalidades dependientes de Firebase se encuentran deshabilitadas.

Sin embargo, la aplicación **puede ejecutarse y visualizarse correctamente**, permitiendo recorrer la interfaz, navegar entre pantallas y conocer el funcionamiento general del sistema.
